How to use:


Download latest version from **release page**

run it and it will open a browser page (allow access apps on this device).

select your client from settings (if your client isn't listed there, select vanilla. if it doesn't work either, select the client's log file or open an issue in this repo)

when in a bedwars arena, it will automatically fetch stats when players join or leave.

to fetch stats of every player, open chat and type a space and then press tab to list all the players (doesn't work on modern version)
